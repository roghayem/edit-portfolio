# 🎬 Edit Portfolio Landing Page

A modern, responsive, and visually appealing **Editor Portfolio Landing Page** built using **HTML, CSS, and JavaScript**. This project showcases a professional portfolio website for a video editor, featuring a clean layout, smooth navigation, engaging animations, and a fully responsive design across all devices.

## ✨ Features

- 🎬 Modern and professional editor portfolio landing page
- 📱 Fully responsive design for desktop, tablet, and mobile devices

## 🚀 How to Run Locally

Clone the repository:

```bash
git clone https://github.com/roghayem/edit-portfolio.git
```

Open the project folder:

```bash
cd edit-portfolio
```

Open `index.html` in your browser.
